# EduFlow Roles & Permissions Matrix

This document defines the 11 role-based access profiles supported by EduFlow Enterprise:
1. SuperAdmin: Unrestricted administrative privileges.
2. InstitutionAdmin: Administrative operations within a single institution.
3. Principal: Executive oversight, faculty evaluation, and institutional metrics.
4. Teacher: Classroom, attendance, grading, and homework operations.
5. Student: Personal learning dashboard, submissions, fee payments, and grades.
6. Parent: Parental oversight of linked children.
7. Accountant: Financial accounting, fee billing, collections, and ledgers.
8. Librarian: Library collection management, circulation, and fines.
9. ExamCoordinator: Examination management, invigilation, and grading schemes.
10. DepartmentHead: Academic curriculum and faculty workload management.
11. Receptionist: Front-office operations, visitor logging, and certificates.
